# BKK STAYPOINT

เว็บรวมข้อมูลที่พักในกรุงเทพมหานคร พร้อมระบบสมาชิก เจ้าของที่พัก และผู้ดูแลระบบ

## ความสามารถ

- ค้นหาที่พักตามเขต ราคา และตำแหน่งปัจจุบัน
- มีรายชื่อครบ 50 เขตของกรุงเทพมหานคร
- สมัครสมาชิกและเข้าสู่ระบบ
- เจ้าของที่พักเพิ่มรายการและอัปโหลดรูปได้ภายหลัง
- แอดมินอนุมัติรายการ และจัดการรูปภาพที่พักได้
- แอดมินเลือกเขตเพื่อค้นหาและแก้ไขข้อมูลที่พัก พร้อมเพิ่มหรือลบรูปภาพได้

## สิ่งที่ต้องมี

- XAMPP (Apache และ MySQL)
- PHP 8 พร้อมส่วนขยาย PDO MySQL
- เว็บเบราว์เซอร์

## วิธีติดตั้งและเปิดใช้งาน

1. วางโฟลเดอร์โปรเจกต์ไว้ที่ `C:\xampp\htdocs\CODEPROJECT`
2. เปิด XAMPP Control Panel แล้วกด Start ที่ **Apache** และ **MySQL**
3. สร้างฐานข้อมูลโดยนำเข้าไฟล์ `database.sql` ผ่าน phpMyAdmin หรือ MySQL command line
4. เปิด `http://localhost/CODEPROJECT/` ในเบราว์เซอร์

## การตั้งค่าฐานข้อมูล

ตรวจสอบการตั้งค่าใน `config.php`:

```php
$host = 'localhost';
$db   = 'bangkok_stay';
$user = 'root';
$pass = '';
```

หาก MySQL ของคุณตั้งรหัสผ่าน ให้แก้ค่า `$pass` ให้ตรงกับเครื่องของคุณ

## หมายเหตุเรื่อง Live Server

Live Server ใช้เปิดหน้า HTML ได้ แต่ไม่สามารถรัน PHP, session หรือ MySQL ได้ครบถ้วน ดังนั้นฟังก์ชันสมัครสมาชิก ล็อกอิน เพิ่มที่พัก และอัปโหลดรูป ต้องเปิดผ่าน Apache/XAMPP ที่ `http://localhost/CODEPROJECT/`

## โครงสร้างไฟล์สำคัญ

- `index.html` — หน้าแรกและตัวกรองค้นหา
- `api.php` — API สำหรับดึงข้อมูลจากฐานข้อมูล
- `config.php` — การเชื่อมต่อ MySQL และ session
- `register.php`, `user_login.php` — สมัครสมาชิกและเข้าสู่ระบบ
- `owner_dashboard.php` — แดชบอร์ดเจ้าของที่พัก
- `admin.php` — หน้าจัดการของแอดมิน
- `upload_image.php`, `delete_image.php` — จัดการรูปภาพ
- `database.sql` — โครงสร้างฐานข้อมูลและข้อมูลเริ่มต้น
- `add_bangkok_districts.sql` — เพิ่มรายชื่อ 50 เขต โดยไม่เพิ่มชื่อซ้ำ
